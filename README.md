# BareFit Smart Timer

## גרסה 0.4.0 Direct — טלוויזיה מארחת את החיבור

רקע אולם הכושר עם גרפיטי BareFit והקרדיט **נוצר על ידי Tomer AI Studio** כלולים בגרסאות הדפדפן והאפליקציה. קובץ הטלוויזיה העדכני הוא `packages/BareFit-AndroidTV-0.4.0-direct.apk`. הטלוויזיה מפעילה את שרת ה-LAN המקומי בעצמה, והטלפון מתחבר אליה ישירות ללא מחשב או ענן. זהו APK בדיקה בחתימת פיתוח.

35 בדיקות אוטומטיות וסימולציה של 72 שעות לכל אחד משני סטודיו עברו. שופרו עומס חישובי השעון, טיפול בחיבור איטי ושמירות ברקע. סימולציה אינה בדיקת חומרה: עדיין נדרשת הרצה של 8–24 שעות בטלוויזיה במכון. פירוט התוצאות והגבולות ב־`VERIFICATION.md`.

מערכת שעון אימונים בעברית, בעיצוב המבוסס על תמונת הלקוח. מנוע JavaScript משותף; ממשקי React למסכים ולמאמן; אפליקציית React Native TV ל־Android, Android TV, iOS ו־tvOS. אין צורך בחשבון או בענן.

## גיבוי באמצעות שלט הטלוויזיה

המסך מפעיל את השעון מקומית גם כשהטלפון או שירות החיבור אינם זמינים. בחיצים בוחרים כפתור, ב־OK מפעילים אותו ובכפתור חזרה סוגרים חלון. אפשר להתחיל, להשהות, לדלג, לעצור לאחר אישור, לבחור אימון מהספרייה המקומית ולשנות הגדרות. בדפדפן, למעלה/למטה עוברים בין שדות וימין/שמאל משנים ערכים. באפליקציית Android/Google TV נתמכים גם כפתורי המדיה הפעלה/השהיה ועצירה. אימונים שקיימים רק בטלפון אינם זמינים למסך מנותק עד שנשלחו אליו. יש לבדוק את השלט בדגם הטלוויזיה בפועל.

## הפעלה מקומית

בגרסת Android TV הטלוויזיה פותחת שרת מקומי על כתובת ה-Wi‑Fi שלה, ושומרת את זהות שני הסטודיו גם לאחר פתיחה מחדש. הטלפון והטלוויזיה צריכים להיות באותה רשת. QR חדש מכיל את כתובת הטלוויזיה והחיבור מתבצע ישירות אליה; אין צורך להפעיל שירות במחשב.

```sh
npm ci
npm run build
npm start
```

פותחים את BareFit בטלוויזיה, בוחרים סטודיו ומציגים QR. בטלפון פותחים את אפליקציית BareFit, בוחרים “חיבור למסך” וסורקים. כל סטודיו מפעיל שעון נפרד.

השרת המקומי המובנה בטלוויזיה מעביר הודעות ואימות. **המסך הוא מקור האמת של השעון**: ניתוק הטלפון אינו עוצר אימון. האפליקציות המותקנות כוללות את הנכסים והמנוע ואינן דורשות מחשב מתווך.

מצב אימון נשמר כל שנייה ובמעברי מצב. לאחר פתיחה מחדש אימון שהיה פעיל משוחזר בהשהיה. סגירה כפויה יכולה לאבד עד שנייה מאז נקודת השמירה האחרונה. אין הבטחת שחזור כאשר מערכת ההפעלה מוחקת את אחסון האפליקציה.

## התכונות

- טיימר מונוטוני, עבודה/מנוחה/הכנה/מנוחה בין סטים/השהיה/סיום.
- התחל, השהה, המשך, עצור עם אישור, שלב הבא והקודם.
- HIIT, Tabata, EMOM, AMRAP, Boxing, Strength ועריכת תוכניות. EMOM מציג חלון עבודה מלא של דקה; ספירת חזרות נעשית בידי המאמן.
- שמירת תוכניות, שכפול, ייבוא וייצוא JSON בממשק Web. המנוע תומך גם ברצף `steps` מותאם שמיובא בקובץ; עדיין אין עורך חזותי לרצף שלבים מורכב.
- QR חד־פעמי למשך שתי דקות, חיבור מאמן אוטומטי, בחירת סטודיו, בקר פעיל אחד ושאר המכשירים בצפייה, ביטול הרשאות. מאמן חדש שמתחבר מקבל את השליטה.
- אימות WebSocket, מזהה פקודה, מספר רצף, ACK וחסימת פקודות כפולות. פקודות אינן נשלחות שוב אוטומטית אחרי timeout כדי למנוע דילוג כפול לא צפוי.
- התראות מקומיות; בדפדפן נדרשת אינטראקציה ראשונית במסך כדי לפתוח שמע לפי מדיניות הדפדפן.
- חיצי שלט/מקלדת, Enter, רווח להפעלה ולהשהיה; שמירת מסך ער כשנתמך. Native משתמש ב־KeepAwake.
- נכסים ופונטים מקומיים, ללא CDN בזמן אימון. Service worker מסייע להפעלה חוזרת בדפדפן ב־HTTPS או localhost; על HTTP ברשת אין להבטיח טעינה מחדש ללא שירות. חבילות TV/Native כוללות את הקבצים מקומית.

## גרסאות Apple ו־Android

```sh
cd native
npm ci
npm run check
npx expo export --platform android --platform ios
```

להכנת TV: הגדירו `EXPO_TV=1` והפעילו `npx expo prebuild --clean`. לטלפון: `EXPO_TV=0` ו־prebuild מחדש. `--clean` מוחק תיקיות Native שנוצרו; הקוד המנוהל וההתאמות שמורים ב־`app.config.js` וב־`plugins/`. יש לגבות שינויים ידניים לפניו. עדיף להשתמש בעותק עבודה נפרד לכל יעד.

- Android: `npx expo run:android --variant release`. הגדרת ה־prebuild הראשונית חותמת במפתח debug, לצורך בדיקות פנימיות בלבד. להפצה יש להגדיר מפתח release פרטי משלכם.
- iOS / Apple TV: יש להריץ prebuild על Mac, להתקין CocoaPods, לבחור צוות חתימה ב־Xcode ולבנות למכשיר המתאים. אין פרויקט Xcode בנוי או IPA חתום בסביבת Windows זו.
- Expo Go אינו תומך ב־React Native TV. יש להשתמש בבנייה ייעודית.
- מסך הגדרות באפליקציה מאפשר להזין את כתובת שירות הסטודיו. באפליקציית הטלפון ניתן להזין מזהה מסך וקוד; QR פותח את ממשק הדפדפן.

## Samsung ו־LG

`npm run build` יוצר `packages/tizen` ו־`packages/webos` עם קוד ונכסים מקומיים.

- Samsung: ב־Tizen Studio מייבאים את התיקייה כפרויקט Web TV, מגדירים תעודת Samsung, בונים חבילת WGT ומתקינים במכשיר פיתוח מורשה. פרסום קבוע דורש מסלול הפצה מתאים; לא נוצרה חתימת לקוח.
- LG: `ares-package packages/webos -o packages`; מתקינים דרך כלי webOS ובודקים על טלוויזיה. Developer Mode מוגבל בזמן ואינו תחליף להפצה קבועה.
- במסכי Settings מזינים כתובת שירות. חבילות מקומיות עשויות להשתמש ב־Origin `null`, `file://` או `app://com.barefit.timer`. יש להוסיף **את ה־Origin שהמכשיר משתמש בו** ל־`ALLOW_ORIGINS` בתהליך השירות, כרשימה מופרדת בפסיקים. אין wildcard בדיקת Origin. הפעלת `null` מאפשרת גם מסמכים מקומיים/מבודדים אחרים לגשת לנקודות החיבור; עדיין נדרשים קוד ואישור למסך וטוקן לכל שליטה.

## גבולות אבטחה ופריסה

הגרסה המקומית משתמשת ב־HTTP/WS כברירת מחדל. האימות אינו מצפין תעבורה, ולכן אין להשתמש בה ברשת ציבורית/לא מהימנה. לפריסה ברשת שאינה מבודדת נדרש TLS עם תעודה מהימנה ו־HTTPS/WSS מול reverse proxy. יש לשמור את `.runtime/rooms.json` פרטי; הוא מכיל hashes של הרשאות. הטוקנים עצמם נשמרים באחסון מקומי במכשיר. אין לשלוח את `.runtime`, `node_modules` או נתוני מכשירים כחלק מהפצת קוד.

### עדכון מצב אולם וקריינות

בתצוגת הדפדפן ובקוד המשותף נוסף מצב אולם עם ספרות גדולות. בהגדרות אפשר לבדוק קול ולחזור לעיצוב העגול.
הספירה אוטומטית: 3 שניות בסיבוב רגיל, בהכנה ובמנוחה; 10 שניות רק בסיבוב האחרון של אימון עם כמה מקטעי עבודה. מקטע יחיד או AMRAP אינם מוכרזים כסיבוב אחרון. תחילת מנוחה מקבלת צליל ללא קריינות. השהיה ועצירה מפסיקות שמע מיד.
הקול הגברי בעברית מסונתז ושמור מקומית. הספרות 3 ו־6 הוקלטו מחדש בקצב רגיל עם ניקוד ושימור העיצורים. כפתור בדיקת הקול מדגים את הסיבוב האחרון וספירה מ־10 גם כשלא מתנהל אימון.
קובצי ההתקנה 0.1.0 שנוצרו קודם אינם כוללים עדכון זה; יש לבנות מחדש מהקוד המעודכן לפני התקנה.


### גרסת טלפון 0.2.0 — בניית אימונים וסריקת QR

מסך הטלפון: `/?mode=coach`. במסך צר זה גם מסך ברירת המחדל. הכפתורים בניית אימון והאימונים שלי זמינים לפני חיבור; התוכניות נשמרות במכשיר. לאחר חיבור כמאמן אפשר לשלוח תוכנית למסך כשהטיימר אינו רץ.
כפתור המצלמה סורק QR ומגיש את בקשת החיבור אוטומטית. האישור במסך נשאר נדרש. בדפדפן בחיבור HTTP מקומי אפשר לצלם את הקוד או לבחור תמונה; הפענוח מתבצע מקומית ללא העלאת תמונה. סריקה חיה בדפדפן דורשת HTTPS או localhost. באפליקציה המקורית יש סריקה חיה במצלמה האחורית והרשאת מצלמה בלבד, ללא הרשאת מיקרופון.
`packages/BareFit-Android-0.2.0-test.apk` הוא קובץ התקנה חדש לטלפון Android, כולל כל תיקוני הקול, מצב האולם, בניית אימונים וסריקה. זהו build לבדיקה עם חתימת פיתוח. קובצי הטלוויזיה 0.1.0 נשארו בגרסה הישנה. iPhone עדיין דורש בנייה וחתימה ב־Mac; בינתיים אפשר להשתמש בדפדפן.
הורדת APK ברשת המקומית: `/downloads/BareFit-Android-0.2.0-test.apk`. בשרת אפשר להגדיר `STUDIO_URL` כדי לבחור כתובת QR מפורשת; אחרת בפתיחה דרך localhost הכתובת נבחרת מממשקי הרשת הזמינים.

## Camera link pairing — October 23, 2026
The current web flow uses the phone's standard Camera/QR scanner: display → Connect coach → scan → tap URL → automatically paired. No photo upload, website camera permission, code entry, or TV approval is required for the new QR link. Phone and hub must be reachable on the same LAN. The camera's tap-to-open is controlled by iOS/Android, not the site.

The QR adds a 256-bit capability in the URL fragment, separate from the short manual code. Both expire after two minutes and are consumed once. Only the capability grants immediate pairing; manual short codes retain host approval. The first device controls, subsequent devices view; revoke an old controller on the display before assigning another. Saved browser credentials reconnect after reload, and a successful exchange removes the fragment. Network requests time out after 12 seconds with a Wi-Fi troubleshooting message.

This update is live in the web build. Native source understands the new capability; previously distributed APKs have not been rebuilt for this update.
